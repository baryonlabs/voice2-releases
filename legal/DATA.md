# 데이터·AI 안내 — 무엇을, 어디로, 왜 보내는가

이 앱이 Mac 밖으로 보내는 정보를 **빠짐없이** 적었습니다. 여기에 없는 정보는 보내지 않습니다.
**녹음(음성) 파일은 어디에도 보내지 않습니다.** 받아쓰기는 Mac 안에서 합니다.

## 1. Baryon Labs가 받는 것: 익명 사용량 통계뿐
| 보내는 것 | 보내지 않는 것 |
|---|---|
| 무작위 설치 ID(계정·기기와 무관한 값), 앱 버전, macOS 버전 | 녹음·대본·요약, 회의 제목, 파일 이름 |
| 날짜별로 기능을 쓴 **횟수** (예: 앱 실행 2, DJI 녹음 처리 1, 요약 복사 3) | 사람 이름, 계정, 이메일, 위치 |

- 하루 한 번까지, 모아 둔 횟수만 보냅니다. 보내고 나면 Mac에 쌓인 횟수는 지웁니다.
- **정보 탭 → 사용 통계**에서 보낼 곳과 보낼 내용을 글자 그대로 확인하고 **끌 수 있습니다**. 끄면 아직 보내지 않은 횟수도 바로 지웁니다.
- 받을 주소가 정해지지 않은 버전은 아무 데도 보내지 않습니다(정보 탭에 "정해지지 않음"으로 표시).
- 통신 과정에서 수집 서버에 IP 주소가 전달되지만, 통계에 저장하거나 설치 ID와 연결하지 않습니다.
- 목적: 어떤 기능이 쓰이는지 파악해 앱을 개선하는 것. 다른 목적으로 쓰거나 제3자에게 팔지 않습니다.
- 광고·추적 기능은 없습니다.
- 예외: AI로 **Baryon AI**를 고른 경우, 아래 2번의 글자(대본)가 Baryon AI 서버로 가서 대본 정리·요약에 쓰입니다. 처리 방식은 「개인정보 처리방침」 1번을 따릅니다.

## 2. AI (이용자가 고른 한 곳으로, 처리할 때만)
| 보내는 것 | 언제 | 왜 |
|---|---|---|
| 받아쓰기 원문(시각·음량·채널 표시 포함)을 10분 단위로 | 대본 정리 | 화자 나누기, 오타·띄어쓰기 고치기 |
| 대본 앞·가운데·끝 일부(최대 약 9,000자) | 상황이 '자동 판별'일 때 | 회의·강의·면접 등 상황 고르기 |
| 정리된 대본 전체, 회의 이름, 상황 | 요약 | 상황에 맞는 요약 만들기 |
| Zoom 채팅(있으면, 최대 2만 자), 참가자 이름 | Zoom 녹화 처리 | 화자 이름·맥락 맞추기 |

| AI | 받는 곳 | 계정 |
|---|---|---|
| Claude Code | Anthropic | 이용자의 Claude 구독 로그인 |
| Codex | OpenAI | 이용자의 ChatGPT 로그인 |
| Anthropic · OpenAI · Gemini API | 각 회사 | 이용자의 API 키 |
| Baryon AI | Baryon Labs 서버 | Baryon Labs가 발급한 키 |
| 사용 안 함 | 없음 | — |

- 각 회사가 받은 내용을 어떻게 다루는지(보관 기간, 학습 사용 여부)는 그 회사의 약관과 계정 설정을 따릅니다. 업무 회의라면 회사가 허용한 AI를 고르세요.
- AI가 쓴 대본·요약은 틀릴 수 있습니다. 중요한 결정·숫자·이름은 원문으로 확인하세요.

## 3. 이용자가 켠 연동 (이용자의 계정·토큰으로)
| 연동 | 보내는 것 |
|---|---|
| Google Drive | 요약·대본 문서를 이용자의 Drive 폴더로 (rclone, 이용자가 로그인한 계정) |
| Notion | 요약·대본 페이지를 이용자가 고른 페이지로 (이용자의 통합 토큰) |
| Zoom 클라우드 API (고급) | 녹화 목록 조회와 내려받기 (이용자가 만든 Zoom 앱 키) |
| 회의록 공개 (MCP) | 켜 둔 동안, 토큰을 가진 프로그램이 이 Mac에 접속해 요약·대본·회의 정보를 가져감. 같은 네트워크·Tailscale 밖으로는 이용자가 직접 열지 않는 한 닿지 않음 |

## 4. 업데이트 확인
하루 한 번 GitHub(공개 저장소 baryonlabs/voice2-releases)에 최신 버전을 묻습니다. 이때 일반적인 웹 요청만 오가며 회의 내용·설치 ID는 보내지 않습니다. 새 버전을 설치하면 내려받은 파일의 체크섬과 개발자 서명(Baryon Labs)을 확인한 뒤 바꿔 끼웁니다.

## 5. 설치·준비할 때 내려받는 것
| 내려받는 것 | 받는 곳 |
|---|---|
| uv(설치 도구), Python, Python 라이브러리 | GitHub(astral-sh), Python 패키지 저장소(PyPI) |
| 받아쓰기 모델(whisper-large-v3-turbo) | Hugging Face |
| rclone | rclone.org |

이때는 일반적인 내려받기 요청만 오가며, 회의 내용은 보내지 않습니다.

## 6. Mac에 남는 것
| 항목 | 위치 |
|---|---|
| 복사한 녹음, 앱에서 녹음한 파일 | `~/dji2note/recordings` |
| 회의록(요약·대본·받아쓰기 원문·정보) | `~/dji2note/notes` |
| 설정(API 키·토큰 포함, 본인만 읽기 600) | `~/.config/dji2note/config.toml` |
| 처리 기록, 회의록을 가져간 기록 | `~/.config/dji2note/state.json`, `feed.json` |
| 로그 | `~/Library/Logs/dji2note.log` |
| 사용 횟수(보내기 전), 통계 켜기/끄기, 설치 ID | `~/Library/Application Support/DJI2Note/usage.json` |
| 엔진·Python·도구 | `~/Library/Application Support/DJI2Note` |
| 받아쓰기 모델 | `~/.cache/huggingface` |

지우려면 위 폴더를 지우고 앱을 휴지통으로 옮기면 됩니다. DJI 마이크 안의 원본 녹음은 지우지 않습니다.

## 7. 녹음 동의
대화를 녹음하기 전에 함께 대화하는 분께 알리고 동의를 받으세요. 녹음·공유와 관련된 법령을 지키는 책임은 이용자에게 있습니다.
